# A Topology of Variables Impacting the 2024 UK General Election

This project uses Topological Data Analysis BallMapper (TDABM) to study the joint relationships  between socioeconomic, migration, and demographic profiles of England/Wales voters which drive their voting preferences at constituency-level. Visualised through point clouds, the project shows geographical heterogeneity of Labour-winning areas and homogeneity in Conservative strongholds.  

## Features
- Extract data from UK Census with minimal manual filtering
- Transform and clean data using Python
- Generate BallMapper

## Tools
- Microsoft Excel
- Python (Pandas, pptx)
